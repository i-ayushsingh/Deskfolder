# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in DeskFolder, please **do not open a public issue**.

Instead, please report security concerns directly via GitHub Private Vulnerability Reporting on the [DeskFolder repository](https://github.com/i-ayushsingh/Deskfolder/security/advisories/new) or contact the maintainer at [github.com/i-ayushsingh](https://github.com/i-ayushsingh).

Please include:
- A description of the vulnerability and its potential impact.
- Clear reproduction steps or proof of concept.
- Your recommended remediation (if any).

We will acknowledge your report promptly and work on a fix before public disclosure.
